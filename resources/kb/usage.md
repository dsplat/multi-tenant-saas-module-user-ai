# User AI 模块

面向**外部主体**（学生 / 家长 / 访客）的 AI 基座。与控制台里的 AI 小助手、数字员工不同——那些服务的是运营人员（Operator），本模块服务的是被服务方（User）。

## 它做什么

提供一条对外问答链路：外部用户提问 → 系统按知识库检索并作答 → 双向内容守护 → 审计留痕。

默认只开放**知识检索**（匿名可问通用政策类问题）。个人信息类查询（课表 / 成绩 / 缴费）需要先完成身份提升，M1 不开放。

## 怎么用

外部用户（或小程序 / 网页前端）调用公开接口：

```
POST /api/v1/user-ai/ask
Body: { "tenant_slug": "your-school", "question": "开学时间是什么时候？" }
```

- `tenant_slug` 必填——公开接口无登录态，必须显式指定租户
- `question` 为提问内容，1–2000 字
- 接口限流：每分钟每 IP 20 次
- 返回 `answer`（回答文本）与 `sources`（相关知识片段）

## 前置条件

1. **知识库已配置**：在「知识库」中接入外部 KB（RAGFlow / Dify / FastGpt / 百炼），并上传校园 FAQ 内容。检索不到内容时接口会返回兜底文案。
2. **模块已启用**：本模块默认关闭，需在模块管理中为租户开启。
3. **AI 模型可用**（可选）：未配置时系统直接返回检索片段，不做 LLM 摘要合成。

## 安全边界

这是框架第一条对外 AI 链路，边界比内部 AI 严格得多：

- **工具面白名单**：只有登记在案的工具对外部用户可见；未登记的工具在执行侧直接拒绝
- **禁用写操作**：对外链路只允许只读工具，发券 / 打标签 / 调积分等一律不可达
- **双向内容守护**：入站拦破坏性指令，出站拦内部标识与敏感信息
- **全程审计**：每次问答都留痕，含主体等级与访客标识

## 常见问题

**Q：回答说「知识库里没有找到相关内容」？**
A：知识库未配置或未上传内容。到「知识库」页面检查外部 KB 连接是否正常、文档是否已上传。

**Q：回答说「该功能当前未开通」？**
A：本模块未在模块管理中启用，或知识库所属模块未开通。

**Q：能查我的课表 / 成绩吗？**
A：不能。个人信息查询需要先完成实名身份提升，当前版本未开放。
